## 2. Правила граматики та команди МА (з ЛР №5)

### 2.1 Правила граматики

| №   | Правило                           |
|-----|-----------------------------------|
| 1   | `I -> If ( A ) { B ; R } C`       |
| 2   | `A -> exp`                        |
| 3   | `B -> smth`                       |
| 4.1 | `R -> B ; R`                      |
| 4.2 | `R -> $`                          |
| 5.1 | `C -> Else X`                     |
| 5.2 | `C -> $`                          |
| 6.1 | `X -> { B ; R }`                  |
| 6.2 | `X -> I`                          |

**Нетермінали:** `I, A, B, R, C, X`  
**Термінали:** `If, (, ), {, }, ;, exp, smth, Else`  
**Маркер кінця:** `#`

### 2.2 Повний список команд магазинного автомата

Позначення:
- **f** — голівка зрушується (лексема споживається)
- **f\*** — голівка не зрушується (лексема залишається)
- `$` як результат — виштовхнути вершину без занесення нічого

| №  | Команда                                 | Коментар                                 |
|----|-----------------------------------------|------------------------------------------|
| 1  | `f(s₀, If, I) = (s, C } R ; B { ) A ()` | Правило 1: починається з термінала      |
| 2  | `f(s₀, exp, A) = (s, $)`               | Правило 2: починається з термінала       |
| 3  | `f(s₀, smth, B) = (s, $)`              | Правило 3: починається з термінала       |
| 4  | `f*(s₀, smth, R) = (s, R ; B)`         | Правило 4.1: починається з нетермінала   |
| 5  | `f*(s₀, }, R) = (s, $)`                | Правило 4.2: анулююче                    |
| 6  | `f(s₀, Else, C) = (s, X)`              | Правило 5.1: починається з термінала     |
| 7  | `f*(s₀, #, C) = (s, $)`                | Правило 5.2: анулююче                    |
| 8  | `f(s₀, {, X) = (s, } R ; B)`           | Правило 6.1: починається з термінала     |
| 9  | `f*(s₀, If, X) = (s, I)`               | Правило 6.2: починається з нетермінала   |
| 10 | `f(s₀, (, () = (s, $)`                 | Збіг термінала `(`                       |
| 11 | `f(s₀, ), )) = (s, $)`                 | Збіг термінала `)`                       |

| 13 | `f(s₀, Else, Else) = (s, $)`           | Збіг термінала `Else`                    |

| 15 | `f(s₀, exp, exp) = (s, $)`             | Збіг термінала `exp`                     |

| 19 | `f*(s₀, $, h₀) = (s, $)`               | Прийняття: вхід та магазин порожні       |

## 3. Конфігурація магазинного автомата

Робота автомата полягає у зміні конфігурацій вигляду `(s, µ, γ)`, де:
- `s` — поточний стан;
- `µ` — залишок вхідного ланцюжка;
- `γ` — вміст магазину (верхній символ праворуч).

**Початкова конфігурація:** `(s₀, µ, h₀I)`  
**Заключна конфігурація:** `(s, $, $)`

Послідовність змін конфігурацій позначається знаком `├`. Автомат розпізнає ланцюжок, якщо від початкової до заключної конфігурації існує несуперечлива послідовність переходів.

## 4. Перевірка роботи команд синтаксичного аналізатора

### 4.1 Ланцюжок 1 — простий `if` без `else` (неповний рядок — очікується помилка)

**Вхідний рядок:**
```
if ( expr ){
    stmt1;
```

**Граматичні символи після сканування:**
```
If ( exp ) { smth ;
```

**Зміна конфігурацій:**

```
(If(exp){smth;#, Ih0)           ├ 1
((exp){smth;#, (A){B;R}Ch0)     ├ 10
(exp){smth;#, A){B;R}Ch0)       ├ 2
(){smth;#, ){B;R}Ch0)           ├ 11
({smth;#, {B;R}Ch0)             ├ 17
(smth;#, B;R}Ch0)               ├ 3
(;#, ;R}Ch0)                    ├ 12
(#, R}Ch0)
  ANALYSIS ERROR — no command found for (input='#', stack_top='R')
```

**Результат:** ❌ ЛАНЦЮЖОК НЕ РОЗПІЗНАНО (Помилка аналізу)

Ланцюжок некоректний, оскільки відсутня закриваюча дужка `}` та нетермінал `R` не може бути згорнутий — у множині ВИБІР правила `R -> $` міститься лише `}`, а не `#`.

## 5. Опис програмної реалізації

Програма реалізована мовою **Python** і складається з таких модулів:

**`scanner(source)`** — лексичний аналізатор на основі скінченного автомата зі станами `S0`, `S1`, `S2`. Розбиває вхідний рядок на токени типів `KEYWORD`, `IDENTIFIER`, `DELIMITER`, `NUMBER`, `ERROR`.

**`tokens_to_grammar_symbols(tokens)`** — перетворює токени у граматичні термінальні символи: `if` → `If`, `else` → `Else`, ідентифікатори типу `expr*` → `exp`, інші ідентифікатори → `smth`, роздільники → відповідний термінал.

**`compute_first_all()` / `first_of_nt()` / `first_of_sequence()`** — обчислення функції ПЕРШ(µ) для кожного правила та кожного нетермінала методом обходу з відстеженням рекурсії.

**`compute_follow()`** — обчислення функції СЛІД(µ) ітеративним алгоритмом фіксованої точки. Стартовий символ `I` отримує маркер кінця `#`.

**`compute_choice(follow)`** — обчислення множини ВИБІР для кожного правила: якщо правило породжує ε, то `ВИБІР = (ПЕРШ \ {$}) ∪ СЛІД`; інакше `ВИБІР = ПЕРШ`.

**`build_pda_commands(choice)`** — будує команди МА за чотирма типами відповідно до методичних вказівок. Повертає список словників з полями `type`, `input`, `stack`, `result`, `comment`.

**`find_command(commands, lexeme, stack_top)`** — пошук відповідної команди переходу за поточною лексемою та вершиною магазину. Повертає команду та її 1-based індекс.

**`simulate_pda(input_tokens, commands, label)`** — виконує симуляцію роботи магазинного автомата. На кожному кроці:
1. Зчитує поточну лексему з вхідної стрічки та вершину магазину.
2. Шукає відповідну команду.
3. Виштовхує вершину магазину.
4. Для команди типу `f` споживає лексему з вхідної стрічки.
5. Заносить результат у магазин у зворотному порядку.
6. Виводить поточну конфігурацію.
7. Фіксує результат — розпізнано (`CHAIN ACCEPTED`) або помилку (`CHAIN REJECTED`).
